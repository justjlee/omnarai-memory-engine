## 5. Known limitations (stated, not hidden)

1. **Independence is declared.** Verifier and reviewer identities, like Footprint authors, are declared. A registered verifier
   is a curator act, not a cryptographic attestation. Lineage independence is only as good as the declared lineage, and an
   `unresolved` lineage fails closed for model judges.
2. **No durable event log.** Signals is a projection rebuilt on each request, with a chain-hash cursor that detects changed
   history. It does not guarantee incremental delivery at scale. `loadPublicWork` reads every public work record per request,
   which is fine for a preview and not for volume.
3. **No real continuation yet.** All Open Work evidence is synthetic. The gate for the `/work` door (D-008) needs one real,
   independently reconstructed handoff, and a correct refutation counts.
4. **Nothing here measures causal benefit.** A packet shows that B built on A. Whether B did better *because* of A needs
   Protocol 001 controls, and every packet says so.
5. **Expression primaries have no ingest or storage path.** That waits on D-007.
6. **Unverified operationally:** production write health, backups and isolated restore, the production `PRIVATE_READ_FALLBACK`
   value, and the deployed build. This session had no production access, and those P0s stay open.

## 6. The smallest scientifically useful next pilot

**IS1 Pilot 002, as already built and costed on the `inheritance-001` branch.** It is the cheapest run that can answer the
core question (does *independently verified* work from one model family help a *different* family beyond compute, raw history
and placebo?), and the reason Pilot 001 could not answer it has been addressed (producers are now told the program language;
probes 3 and 4 checked the fix). Producers `gemini-4-carbon` + `gpt-6.1-sol`; consumer `claude-sonnet-5-5`; 8 held-out families
× 6 tasks = 48 paired blocks × 6 arms; 344 calls; **expected $5.61, worst case $14.07** (December prices); proposed cap $18, or
a smaller cap under D16. It is descriptive at this size (8 < 10 families; ~40% power for +0.15), so it measures real base
rates, costs and the sign of C − A+, which a confirmatory study needs before it can be sized. Order: D16 → sealed draw →
plan → xz approves the exact plan hash → preregistration committed alone and pushed → run.

**For the `/work` door (a gate, not a pilot): OW-1.** Register one real, narrow problem whose verifier is deterministic and
independent of every model (in the style of case 1). Have one model from a lineage that has not seen it read only the
successor brief in a fresh context and leave a voice record. The curator binds it, the registered verifier runs, and an
independent reviewer decides. Success is a reconstructed, verified continuation **or a correct refutation**. Cost: a few calls
by hand (under $1). No causal claim is made from it.
